# ✍️ Рукопись А4 (HandText A4)

Веб-приложение для мгновенного превращения обычного печатного текста в реалистичные рукописные листы формата **А4**, полностью готовые к печати на принтере или сохранению в PDF.

---

## 🚀 Возможности

1. **Реалистичные рукописные шрифты с поддержкой кириллицы**:
   - `Bad Script` — аутентичный почерк школьной/студенческой тетради.
   - `Caveat` — быстрый, живой современный почерк с размашистыми росчерками.
   - `Marck Script` — аккуратная связная каллиграфия отличника.
   - `Neucha` — разборчивый полупечатный почерк.
   - `Pangolin` — мягкий округлый почерк для заметок.
   - `Shantell Sans` — чертежный рукописный печатный шрифт.

2. **Физическая точность формата А4 (210 × 297 мм)**:
   - Листы сверстаны по точным пропорциям стандарта ISO 216 (А4).
   - Автоматическая разбивка длинных текстов на несколько страниц А4 без обрезки слов.
   - Поддержка принудительного разрыва страниц (`---`).

3. **Органический алгоритм реализма (Jitter Engine)**:
   - **Микро-повороты слов**: естественные отклонения кисти руки при письме.
   - **Неровность строк (Wobble)**: органический дрейф строки относительно линейки.
   - **Эффект нажима и капиллярного впитывания чернил**: полупрозрачность пасты и микро-размытие.
   - **Кнопка перегенерации случайности**: каждая генерация уникальна.

4. **Типы бумаги**:
   - 🟦 **Тетрадь в клетку (5×5 мм)** — классическая школьная сетка.
   - 📑 **Тетрадь в линейку (8 мм)** — разлинованный тетрадный лист.
   - 📄 **Чистый офисный лист А4** — для заявлений, объяснительных и официальных записок.
   - 📜 **Помятый лист с текстурой** — текстура настоящей бумажной ткани и легких складок.
   - 🍂 **Винтаж / Крафт бумага** — теплый оттенок состаренной бумаги.
   - 🔴 **Красные тетрадные поля** с настраиваемой шириной (от 20 до 45 мм).

5. **Цвета чернил и ручек**:
   - Классическая синяя шариковая ручка
   - Темно-синяя густая паста
   - Черная гелевая ручка
   - Фиолетовые чернильные чернила
   - Простой графитовый карандаш
   - Красная и зеленая ручки
   - Палитра выбора любого кастомного цвета

6. **Особые маркеры форматирования**:
   - `~текст~` — реалистичная помарка / зачеркивание слова ручкой от руки.
   - `==текст==` — полупрозрачное выделение цветным маркером-текстовыделителем.
   - `**жирный**` — усиленный нажим стержня.
   - `---` — переход на следующий лист А4.

7. **Экспорт и печать**:
   - 🖨️ **Прямая печать А4** (`Ctrl + P` или кнопка): оптимизированные CSS `@media print` стили — убирают весь интерфейс программы и идеально центрируют лист без белых кромок.
   - 📄 **Скачать PDF** — экспорт многостраничного PDF файла в векторных размерах А4.
   - 🖼️ **Скачать PNG** — четкое изображение высокого разрешения (2x DPI).

## 🛠️ Запуск локально

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере:
   ```
   http://localhost:5173/
   ```

## 🖨️ Совет по печати на принтере
В диалоговом окне печати браузера (Chrome / Edge / Яндекс):
- Убедитесь, что выбран формат бумаги: **А4**.
- Включите галочку: **«Фоновая графика» / «Background graphics»** (чтобы напечаталась тетрадная клетка или линейка).
- Поля страницы: выберите **«По умолчанию»** или **«Нет»**.
